# 安全说明

[← 返回主 README](../README.md)

shub **不做任何认证**。任何能访问 `share` 监听端口的人都可以：

- 读取串口设备的所有输出；
- 向串口设备发送任意指令。

**这适合完全可信的局域网环境。** 如果内网不完全可信，请在网络层面做隔离：

- 通过防火墙只允许特定 IP 访问 `share` 端口；
- 通过 VLAN 隔离设备网络；
- 通过 VPN 接入后再访问；
- 在 `config/tcp.py` 里把 `BIND_ADDR` 设为特定内网网卡地址，避免监听所有网卡。

**不要将 `share` 端口暴露到公网。**

## 为什么不做认证

- 定位是可信局域网；
- 加认证会让 MobaXterm / PuTTY 直连变复杂，失去“无客户端软件”优势；
- 安全边界应由网络层负责，而不是在字节转发层做。
